# American History: Versions A and B

Two separate built-in Classic packs for an international group of teens. Each has **42 questions across the same seven categories**, with one clue per category at **100, 200, 300, 400, 500 and 1000 points** (17,500 authored points per pack). All 84 clues, fact keys and accepted answers are distinct between versions. Difficulty is editorially matched by category and tier, not calibrated from player results.

## Play either version

Start the normal integrated server with `npm start` (Node 22+), or use the existing platform launcher. Open the printed Host URL, choose **Classic**, then choose **American History: Version A** or **American History: Version B** in **Question pack** before pressing **Start Game**. Both appear as separate cards. Pack titles wrap so the version letter remains visible; the mobile lobby fits its viewport without clipping the right-hand cards. Players join the room from their phones as usual. All existing packs remain available.

Quick plays 16 board clues (4 categories × 4 values); Standard plays 25 (5 × 5); Marathon plays 36 (6 × 6). The seventh category ensures an unused question is available for Final even in Marathon. Final selects from unused questions under the existing rules. No new scoring, timers, bonuses, wagering or answer-reveal rules are introduced.

For a useful comparison, keep game length, timer and rules identical in A and B. Use Marathon to include the full point ladder. The existing comeback bonuses, Daily Doubles and Final wagers affect total scores, so correct-answer counts are also useful. The packs compare these players in this game; they are not a calibrated test of national knowledge. Keep the source files and this authoring reference away from players before both games.

## Authoring and verification

- Sources: `src/games/trivia/packs/american-history-a.ts` and `american-history-b.ts`.
- Registration: generated by `npm run packs:sync`; no custom picker or engine path.
- Content audit: `npm run questions:check` plus `tests/trivia/americanHistory.test.ts` checks matching coverage, distinct answers/facts/prompts, and literal answer giveaways across both packs. Numbers/ordinals and aliases shorter than four characters are excluded from the literal check because they also occur incidentally. Editorial review covers semantic overlaps.
- Engine coverage: both versions at all three lengths, three players, positive/negative base scoring on another player's turn (the fixed comeback boost applies only to the selecting player), unrevealed player/display answers, and unused Final questions.
- Browser coverage: `e2e/american-history.spec.ts` selects and launches each version through the real server, joins three independent phone sessions, checks mobile/desktop card fit, buzzes, reveals and confirms synchronized scores on the phone and Presentation screen.
- Full checks: `npm run questions:check`, `npm run typecheck`, `npm run typecheck:server`, `npm run lint`, `npm test`, `npm run build`, `npm run test:e2e`, `npm run test:e2e:webkit`.
